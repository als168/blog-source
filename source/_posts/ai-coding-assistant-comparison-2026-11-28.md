想找个 AI 编程助手的人，现在基本绕不开这三个名字：Cursor、GitHub Copilot、通义灵码。它们都能补全代码、能聊天改代码，看着像一回事，实际上走的路不太一样。价格我对照官方页面核过一遍，下面按「你是谁、你每天写多少代码、你愿不愿意花钱」来分。

## 先看价格：三家都有免费档，但免费的意思不一样

GitHub Copilot 的免费档最实在：每月 2000 次代码补全，加上 50 次对话或者 Agent 请求，用的是入门级模型，不用绑卡，GitHub 账号就能开。付费档 Pro 是每月 10 美元，Pro+ 39 美元，Max 100 美元。计费方式是 AI Credits，1 个积分等于 0.01 美元，不同模型、不同任务耗的积分不一样。有一点值得注意：代码补全和「下一处修改」建议在付费档是不耗积分、无限次的，耗积分的主要是聊天和 Agent 会话。

Cursor 的免费档叫 Hobby，官方没有公布具体的次数上限，只说 Agent 请求和 Tab 补全都有限额，新账号还有大约一周的 Pro 体验。付费从 Pro 起，每月 20 美元，包含 20 美元的额度池和无限 Tab 补全；Pro+ 每月 60 美元，Ultra 200 美元，团队版每人每月 40 美元。年付大约打八折，Pro 年付约每月 16 美元。Cursor 的额度是按模型消耗的，用得猛的话，月费之外还可能产生超额费用，官方自己的估计是每天重度用 Agent 的人，一个月总花费在 60 到 100 美元之间。

通义灵码的个人版免费，这是它官网首页就写明的。没有按月收费的个人档，企业版另外谈。功能上包括行间代码生成、研发问答、多文件自动编辑和编程智能体，支持 200 多种语言。对国内开发者来说，还有一个实际好处：国内直连，不用折腾网络。

## 再看用法：三个工具，三种手感

Cursor 是一个完整的编辑器，基于 VS Code 改的。你打开它就是在里面写代码，Agent 模式可以自己拆任务、改多个文件、跑终端命令。它的强项是「人在编辑器里，AI 也在编辑器里」，改代码、看 diff、跑测试都在一个地方完成。适合那种每天泡在编辑器里、愿意让 AI 动手改代码的人。缺点是它自成一体，你原来的 VS Code 配置和插件要重新适应一遍。

GitHub Copilot 是反过来的思路：它跟着你走。VS Code、JetBrains、Xcode、Vim、终端、网页、手机上都有，还能从 GitHub 的 Issue 出发，让 Agent 自己开分支、写代码、提 PR，整个流程都在 GitHub 里闭环。它的强项是跟 GitHub 的协作流程贴得最紧：改代码、审 PR、处理合并冲突，都在你本来就在用的地方。适合团队已经在用 GitHub 做协作、或者经常要在多个工具之间切换的人。

通义灵码是插件形态，装进你现有的编辑器里用。它的编程智能体也能自主拆任务、用工程检索和文件编辑工具端到端完成编码任务，多文件自动编辑和 Diff-Review 是它主打的体验。另外它背后有阿里云的文档和研发知识库，问阿里云相关的问题答得比较顺。适合国内开发者，尤其是已经在用阿里云、或者主要写中文注释和文档的团队。

## 怎么选：按你的情况对号入座

预算为零，先试免费档。偶尔写写代码、学生党、想先体验一下 AI 编程，Copilot Free 的 2000 次补全加 50 次对话够用一阵子；通义灵码个人版免费，没有次数上的硬性宣传，更适合每天都写代码但不想花钱的人。Cursor 的 Hobby 免费档额度有限，更适合先体验一周，再决定要不要付费。

每天写代码，想让 AI 帮你改多文件、跑测试，Cursor Pro 每月 20 美元是多数人的选择。它的 Agent 在编辑器里动手的能力目前是最顺的，代价是月费不低，而且用得越猛，超额部分越多，账单要自己盯着。

已经在 GitHub 里协作，想让 AI 跟着 Issue 和 PR 走，选 Copilot Pro，每月 10 美元。价格是三家里付费档最低的，而且补全不限次，对每天写代码的人来说，成本最好算。

在国内开发，网络要稳、文档要中文、最好不花钱，通义灵码个人版先装上再说。它在国内直连，200 多种语言都支持，企业要用的话再谈团队版。

## 几个提醒

第一，价格以官网实时页面为准。AI 工具的定价改得很快，Cursor 在 2025 年 6 月就改过一次计费方式，从固定次数改成额度池。本文的价格是 2026 年 11 月 28 日核对的：Copilot 来自 GitHub 官网，通义灵码来自阿里云官网，Cursor 的价格来自多家评测对照官方定价页后的整理，付费之前请再打开官网确认一遍。

第二，别只看月费，要看你的用量怎么烧。Cursor 和 Copilot 都是额度制，用高级模型、跑长 Agent 会话烧得快；通义灵码个人版免费，但企业场景的用量规则要看团队版的说明。

第三，我没有逐一实测三款的 Agent 效果，本文按官方定价页与功能页整理，没写实测细节。最好的办法是三个免费档都装上，用自己真实的项目各写一周代码，手感这东西，别人说得再多也不如自己敲几行。
